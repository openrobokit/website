Motion Planning

GraspTrajBuilder filters grasps, optionally IK-converts them onto an arm, then plans with build_motion_planner: a WarpPlanner by default, or its base TorchPlanner when MotionPlannerConfig.backend is "torch".

lift_qpos: Optional[Float[torch.Tensor, 'n_scenes n_grasps num_dofs']],

) -> Tuple[Float[torch.Tensor, 'n_scenes n_grasps num_steps num_dofs'], Float[torch.Tensor, 'n_scenes n_grasps']]

One robokit plan: start → pre-grasp against the scene, then grasp, the locked hold and the lift without it.

robokit times every segment but the hold, which keeps num_steps_holding; the plan is sampled every control_dt and padded with its last frame to num_steps when shorter. Returns it and the start → pre-grasp penetration.
