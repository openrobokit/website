attribute[source]
DatasetConfig.num_actions: int = 64

Successful action trajectories sampled per scene, with replacement when a scene has fewer.

attribute[source]
DatasetConfig.num_points: int = 2048

Point-cloud points per scene, with replacement when the cloud is smaller.

attribute[source]
DatasetConfig.return_actions: bool = True

Return the (num_actions, 3, D) supervision tensor; training needs it and evaluation turns it off.

attribute[source]
DatasetConfig.return_graspness: bool = False

Return per-point graspness and the best conditioning-point indices, for local-feature SpConv policies; needs data processed with enable_contact_extraction.

attribute[source]
DatasetConfig.return_object_pointcloud_only: bool = False

Sample only target-object points instead of the full cropped scene cloud.

attribute[source]
DatasetConfig.cache_in_memory: bool = False

Cache observations and actions in RAM; sampling stays unchanged.

attribute[source]
DatasetConfig.return_rgb: bool = True

Include RGB and camera poses when available.

attribute[source]
DatasetConfig.fuse_views: int = 0

Object-only multi-view data: fuse view 0 (the head) with up to this many other views, a random count per sample, into one cloud. 0: one random view.

attribute[source]
DatasetConfig.view_noise: float = 0.0

With fuse_views: std of each view's rigid misalignment, meters (translation) and x10 radians (rotation).

attribute[source]
DatasetConfig.point_noise: float = 0.0

With fuse_views: std of per-point Gaussian noise (m).

attribute[source]
DatasetConfig.aug_prob: float = 0.0

With fuse_views: probability of the perception augmentation (datasets/perception_aug.py) per sample; needs renders that keep the neighbours (extract_segments=[]) and camera poses in the processed h5.

attribute[source]
DatasetConfig.aug_keep_min: float = 0.1

Perception aug: fused-cloud keep fraction, log-uniform in [aug_keep_min, 1].

attribute[source]
DatasetConfig.aug_voxel_max: float = 0.0

Perception aug: voxel dedup size (m), applied with p 0.5 (the old gate pipeline's 3 mm thinning).

attribute[source]
DatasetConfig.aug_drop_wrist_prob: float = 0.0

Perception aug: probability of the head view alone (no wrist view).

attribute[source]
DatasetConfig.aug_rgb_prob: float = 0.0

Perception aug: probability of the RGB / MoGe depth-error model (per sample).
