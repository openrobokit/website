Quickstart

Try it without installing

Run this to start the interactive grasp gallery:

shell
uvx --from graspkit python -m graspkit.gallery.grasp_optim

Pick a hand, arm, and object. Press Optimize to generate grasps, then browse them with the Grasp slider. The gallery caches results for the next visit.

Optimize one grasp

After installing, run the smallest grasp optimization example:

shell
uv run src/graspkit/examples/grasp_optim/01_basic.py

It optimizes xHand grasps for one YCB object and opens a Viser page to browse the results. Grasp optimization needs a CUDA GPU.
