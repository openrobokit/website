User Guide

Overview

GraspKit is an end-to-end toolkit for manipulation across various robot embodiments, including grippers and dexterous hands. It synthesizes grasps, plans trajectories, trains policies, and deploys them in simulation or on real robots; it is built on top of RoboKit.

Key features

  • Fast grasp optimization. GPU optimizers refine thousands of grasp seeds per batch against cached scene geometry. See Grasp optimization.
  • Performant policy training. Train grasp policies on processed point clouds and successful trajectories, with multi-GPU support. See Training.
  • Across embodiments. Use grippers and dexterous hands in arm, hand, and humanoid configurations. See the robot catalog.
  • Simulation validation. Filter and motion-plan grasps, then test them in physics simulation. See Simulation deployment.
  • Real-world validation. Run trained policies on xArm and Vega robots with calibrated cameras and collision-checked motions. See Real deployment.
