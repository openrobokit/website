Installation

RetargetingKit needs Python 3.10 or newer.

shell
uv add retargetingkit
shell
pip install retargetingkit

From source

shell
uv add git+https://github.com/openrobokit/retargetingkit.git
shell
pip install git+https://github.com/openrobokit/retargetingkit.git

To work on RetargetingKit itself, clone the repository and run uv sync. See the Development Guide.

Extras

ExtraWhat it adds
visBrowser galleries and Viser previews.
contactHand-object contact examples.
vision-pro, pico, manus, axisLive motion sources; see Sources.
xarm, inspire, abilityPhysical arm and hand targets; see Targets.
realsenseRealSense camera source.
rby1, dexmateHumanoid hardware connections.

The pico, manus, and axis extras use wheels from a separate index:

shell
uv add "retargetingkit[manus]" --index https://jianglongye.github.io/torch_packages_builder
shell
pip install "retargetingkit[manus]" --extra-index-url https://jianglongye.github.io/torch_packages_builder

See Assets, then start with the Quickstart.
