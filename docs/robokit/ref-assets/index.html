Built-in Robots & Datasets

Robot descriptions and datasets live in the HuggingFace dataset openrobokit/robokit.

Assets are under their own licenses; see license files and outstanding gaps.

Consuming

Import a named asset module and use its static Path symbols. Required files are downloaded and cached automatically. Use fetch() for paths without static symbols:

python
from robokit.assets import fetch
from robokit.assets.robots.humanoids import unitree_g1

unitree_g1.URDF_PATH
unitree_g1.COLLISION_SPHERE_PATH
fetch(["datasets/sfu/**"]) / "datasets/sfu/0005/x.npz"
from robokit.assets import fetch
from robokit.assets.robots.humanoids import unitree_g1

unitree_g1.URDF_PATH
unitree_g1.COLLISION_SPHERE_PATH
fetch(["datasets/sfu/**"]) / "datasets/sfu/0005/x.npz"
assert unitree_g1.URDF_PATH.is_file()
Note

Files are pinned to one dataset commit and cached under ~/.robokit/, so imports work offline.

Self-collision ignore sets

Each robot lists the link pairs that always touch, so self-collision terms skip them. Each geometry representation has its own set. Match it to your SelfCollisionTask representation (sphere by default):

python
robot = Robot.load(
    xhand.URDF_PATH_RIGHT,
    load_collision_spheres=True,
    collision_spheres_path=xhand.COLLISION_SPHERE_PATH_RIGHT,
    self_collision_ignore_path=xhand.SPHERE_SELF_COLLISION_IGNORE_PATH_RIGHT,  # or CAPSULE_...
)
from robokit.robo import Robot
from robokit.assets.robots.end_effectors import xhand

robot = Robot.load(
    xhand.URDF_PATH_RIGHT,
    load_collision_spheres=True,
    collision_spheres_path=xhand.COLLISION_SPHERE_PATH_RIGHT,
    self_collision_ignore_path=xhand.SPHERE_SELF_COLLISION_IGNORE_PATH_RIGHT,  # or CAPSULE_...
)
assert robot.spec.has_collision_spheres

MJCF variants have only MJ_CAPSULE_... sets. Robots without collision spheres have no sphere set.

For asset layout and authoring, see the Development Guide.

User-provided body models

Download MANO or SMPL-X from its official website after accepting its license. Put the files you need under ~/.robokit/body_models/, or set ROBOKIT_BODY_MODELS to another folder:

  • mano/MANO_RIGHT.pkl or mano/MANO_LEFT.pkl
  • smplx/SMPLX_NEUTRAL.npz, smplx/SMPLX_MALE.npz, or smplx/SMPLX_FEMALE.npz
python
from robokit.smplx import load_mano, load_smplx

hand = load_mano()  # or load_mano("/path/to/MANO_RIGHT.pkl")
body = load_smplx()
from robokit.smplx import load_mano, load_smplx

hand = load_mano()  # or load_mano("/path/to/MANO_RIGHT.pkl")
body = load_smplx()
assert hand is not None and body is not None

NPZs load directly. PKLs convert once beside the originals, so the folder must be writable. RoboKit never downloads body models.
