Solve camera extrinsics from initial_extrinsic.

Lifecycle

  1. Build the solver for new observations, or reuse stored data.
  2. Reset variables and sample camera or joint candidates.
  3. Optionally initialize q from keypoints, then run native population LM.
  4. Retain the best result and restart if mask mismatch remains high.

Data:

  • Any target supplied: replace data and rebuild the solver.
  • No targets supplied: reuse stored data.

) -> torch.Tensor

Fit synchronized silhouettes and optional keypoints to a joint trajectory; an empty mask with positive weight constrains absence.

Lifecycle

  1. Validate calibration, timestamps and observations; normalize mask costs by area.
  2. Initialize a coherent trajectory, or use supplied q without frame sampling.
  3. Fit the coupled image, temporal and optional camera system.
  4. Resolve shared joint offsets against source frames and retain joints and cameras.

Outputs

last_frame_q: Independent frame fits, or the supplied q. last_initial_q: Coherent path before coupled refinement, or the supplied q. last_q: Final joint result [T,J] on the input device.

Silhouettes [T,V,H,W] in [0,1].

Finite, strictly increasing source times [T].

Nonnegative mask weights [T,V]; zero marks a missing view.

Optional joint trajectory [T,J]; skips frame sampling.
