robokit.geom.WarpScene(
num_scenes: int,
device: Device = 'cpu'
)

Heterogeneous batched scene SDF query.

Example

python
>>> import numpy as np
>>> import torch
>>> import warp as wp
>>> from robokit.geom.geoms import SphereGeom
>>> wp.init()
>>> scene = WarpScene(num_scenes=1, device="cpu").add(
...     SphereGeom(np.array([1.0]), np.array([0, 1], dtype=np.int32))
... )
>>> signed_dists, _, _ = scene.query_sdf_torch(
...     torch.tensor([[2.0, 0.0, 0.0], [0.5, 0.0, 0.0]]),
...     torch.tensor([0, 2]),
... )
>>> bool(torch.allclose(signed_dists, torch.tensor([1.0, -0.5])))
True
>>> normal_jacobians = wp.empty(1, dtype=wp.mat33, device="cpu")
>>> _ = scene.query_sdf(
...     wp.array([[2.0, 0.0, 0.0]], dtype=wp.vec3, device="cpu"),
...     scene_indices=wp.array([0], dtype=wp.int32, device="cpu"),
...     out_normal_jacobians=normal_jacobians,
... )
>>> np.allclose(normal_jacobians.numpy()[0], np.diag([0.0, 0.5, 0.5]))
True
>>> observed = wp.empty(1, dtype=wp.bool, device="cpu")
>>> _ = scene.query_sdf(wp.array([[2.0, 0.0, 0.0]], dtype=wp.vec3, device="cpu"),
...     scene_indices=wp.array([0], dtype=wp.int32, device="cpu"), out_observed=observed)
>>> bool(observed.numpy()[0])  # analytical geometry is fully known
True
from robokit.geom.scene import WarpScene

import numpy as np
import torch
import warp as wp
from robokit.geom.geoms import SphereGeom
wp.init()
scene = WarpScene(num_scenes=1, device="cpu").add(
    SphereGeom(np.array([1.0]), np.array([0, 1], dtype=np.int32))
)
signed_dists, _, _ = scene.query_sdf_torch(
    torch.tensor([[2.0, 0.0, 0.0], [0.5, 0.0, 0.0]]),
    torch.tensor([0, 2]),
)
bool(torch.allclose(signed_dists, torch.tensor([1.0, -0.5])))
normal_jacobians = wp.empty(1, dtype=wp.mat33, device="cpu")
_ = scene.query_sdf(
    wp.array([[2.0, 0.0, 0.0]], dtype=wp.vec3, device="cpu"),
    scene_indices=wp.array([0], dtype=wp.int32, device="cpu"),
    out_normal_jacobians=normal_jacobians,
)
np.allclose(normal_jacobians.numpy()[0], np.diag([0.0, 0.5, 0.5]))
observed = wp.empty(1, dtype=wp.bool, device="cpu")
_ = scene.query_sdf(wp.array([[2.0, 0.0, 0.0]], dtype=wp.vec3, device="cpu"),
    scene_indices=wp.array([0], dtype=wp.int32, device="cpu"), out_observed=observed)
bool(observed.numpy()[0])  # analytical geometry is fully known

WarpScene.query_sdf(
points: wp.array,
scene_offsets: Optional[wp.array] = None,
scene_indices: Optional[wp.array] = None,
query_mask: Optional[wp.array] = None,
distance_only: bool = False,
out_signed_dists: Optional[wp.array] = None,
out_normals: Optional[wp.array] = None,
out_closest_points: Optional[wp.array] = None,
record_tape: bool = True,
out_normal_jacobians: Optional[wp.array] = None,
out_observed: Optional[wp.array] = None
) -> Union[wp.array, Tuple[wp.array, wp.array, wp.array]]

Query the scene SDF (min over all attached geoms) at points.

Parameters
pointswp.arrayrequired

Query points, any shape (flattened to n internally).

scene_offsetsOptional[wp.array]= None

CSR boundaries into the flat points, int32, length num_scenes+1. Pass exactly one of scene_offsets / scene_indices.

scene_indicesOptional[wp.array]= None

Scene id of each point, int32, one per point. Skips the derivation launch, so hot loops pass a pre-built map here.

query_maskOptional[wp.array]= None

Optional per-point gate, int32, length n. Points with mask 0 skip every geom kernel.

distance_onlybool= False

Skip the normal/closest computation (~2x faster) and return only signed distances.

out_signed_distsOptional[wp.array]= None

Optional preallocated output; required shape n. Hot loops and CUDA-graph capture pass all out_* so no allocation happens per call.

out_normalsOptional[wp.array]= None

Optional preallocated output, shape n.

out_closest_pointsOptional[wp.array]= None

Optional preallocated output, shape n.

record_tapebool= True

Record the launches on an active wp.Tape; False keeps the query off the gradient.

out_normal_jacobiansOptional[wp.array]= None

Optional preallocated wp.mat33 output, one per point. Entry (i, j) is the derivative of normal component i with respect to point coordinate j. Mesh face normals have zero derivatives; voxel and primitive normals use analytical derivatives of the active query branch. Derivatives at cell, face, or closest-object switches are discontinuous.

out_observedOptional[wp.array]= None

Optional device bool array, one per point. True when every sensor map in the scene has observed the queried voxel; outside a sensor map or masked out is False. Meshes and analytical geometry leave this status unchanged. Unknown status never skips distance checks.

Returns
Union[wp.array, Tuple[wp.array, wp.array, wp.array]]

Flat (n,) views: signed_dists if distance_only, else (signed_dists, normals, closest_points). Points in an empty scene get MAX_DIST distance and zero normals.

method[source]
WarpScene.query_sdf_torch(
query_points: torch.Tensor,
scene_offsets: torch.Tensor,
poses: Optional[Dict[BaseGeom, torch.Tensor]] = None,
scales: Optional[Dict[BaseGeom, torch.Tensor]] = None
) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]

Differentiable scene SDF query (per-point min over all attached geoms).

Parameters
query_pointstorch.Tensorrequired

Query points, shape (n, 3), differentiable.

scene_offsetstorch.Tensorrequired

CSR boundaries into the points, length num_scenes+1.

posesOptional[Dict[BaseGeom, torch.Tensor]]= None

Optional per-geom pose overrides, (count, 4, 4) tensors keyed by attached geom. Overridden geoms are queried on these poses and receive gradients; other geoms use their stored (non-differentiable) transforms.

scalesOptional[Dict[BaseGeom, torch.Tensor]]= None

Optional per-geom scale overrides, (count,) tensors keyed by attached geom. Same semantics as poses.

Returns
Tuple[torch.Tensor, torch.Tensor, torch.Tensor]

(signed_dists, normals, closest_points) torch tensors, shapes (n,), (n, 3), (n, 3). Gradients flow to query_points and to the poses/scales tensors of whichever geom is closest at each point.
