x: wp.array,

max_step: float = 0.0

Bases: Var

A batched vector optimization variable on Euclidean space.

Example

python
>>> from enum import Enum
>>> from robokit.opt import VarValues
>>> class Key(Enum):
...     X = 0
>>> var = VectorVar(wp.array([[1.0, 2.0]], dtype=wp.float32))
>>> values = VarValues.from_var(var, Key.X)
>>> result = values.integrate(wp.array([[0.5, -1.0]], dtype=wp.float32))
>>> result.get(Key.X).x.numpy().tolist()
[[1.5, 1.0]]
>>> capped = VectorVar(wp.zeros((1, 2), dtype=wp.float32), unit=10.0, max_step=1.0)  # moves 10x, 1 at most
>>> capped.integrate(wp.array([[0.0625, 1.0]], dtype=wp.float32)).x.numpy().tolist()
[[0.625, 1.0]]

robokit.opt.optimizer.Optimizer(
terms: Union[Task, Sequence[Task]],
config: Optional[OptimizerConfig] = None,
device: Optional[wp_device_type] = None,
active_dof_mask: Optional[wp.array] = None
)
Bases: abc.ABC

Warp optimizer lifecycle with shared Jacobian machinery for gradient optimizers and LM's CG step.

Solve sequence:

  1. reset: build once, slice to batch size, optionally capture a graph, then call _start.
  2. Repeat step max_iter times, replaying the iteration graph or running _step_body.

Subclass hooks:

  • _build(var): allocate all buffers at the first var's batch size (max_batch_size).
  • _BATCH_BUFFERS: identify batch-leading arrays and vars to slice per solve.
  • _start(var): initialize per-solve damping/history/schedules and starting cost.
  • _step_body(var): run one iteration in place using kernels only.

Fit a sampling distribution from costs, as in MPPI and evolution strategies.

Each round:

  1. Move centers using scored draws and refit std.
  2. Draw num_draws std-scaled normals per center; draw zero has no noise and preserves the center.

Center updates:

  • sample_mode=mean: cost-weighted mean of noise.
  • sample_mode=best: cheapest draw's current position, including any optimizer movement.

Cost weighting:

  • softmax: Boltzmann weights over negative cost at temperature.
  • fitness_shaping: standardized costs scaled by learning_rate.

Capacity/reset controls:

  • instances: maximum center population; narrower solves use prefixes.
  • std_reset and temperatures: caller-adjustable per-instance settings; reset restores std from std_reset.
  • lower and upper: optional (instances, tangent_dim) bounds on a vector variable's drawn values; each draw is clamped to its center's and its noise follows.
