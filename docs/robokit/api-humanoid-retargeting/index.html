Online humanoid retargeting with input joints ordered by human_joint_names.

Lifecycle

  1. __init__ stores the robot, configuration, and caller-owned scene.
  2. warmup(batch_size) builds batch-shaped buffers and solvers.
  3. solve(T_world_human) advances one batched frame from Warp inputs.

T_world_human: wp.array,
human_heights: Optional[wp.array] = None,

Retarget one batched human frame from Warp inputs.

Lifecycle

  1. Validate the shape fixed by warmup(...).
  2. Update temporal terms from the previous robot state.
  3. Compute targets and candidate states.
  4. Solve once, retain the state, and write the requested output buffer.

>>> config = HumanoidRetargeterOnlineConfig(
...     link_mapping={
...         "torso": LinkMapping("spine", np.zeros(3), np.zeros(4)),
...         "hip": LinkMapping("pelvis", np.zeros(3), np.zeros(4)),

...     scale_table={"spine": 0.9},
... )
>>> arrays = config.target_arrays(config.human_joint_names)
>>> arrays.joint_indices.tolist(), arrays.scales.tolist()

HumanoidRetargeterOffline.solve(
T_world_human: wp.array,
valid_lengths: Optional[wp.array] = None,
human_heights: Optional[wp.array] = None,
out: Optional[wp.array] = None,
target_overrides: Optional[Dict[str, np.ndarray]] = None
) -> wp.array

Retarget one padded [B, T, J] Warp trajectory batch.

Lifecycle

  1. Validate the shape fixed by warmup(...).
  2. Compute all frame targets and independent IK warm starts.
  3. Reset the cached trajectory state and valid-frame masks.
  4. Solve once and write the requested padded output buffer.
Parameters
T_world_humanwp.arrayrequired

Human joint transforms with shape (batch, frames, joints).

valid_lengthsOptional[wp.array]= None

Optional valid frame count for each padded batch element.

human_heightsOptional[wp.array]= None

Optional human height in meters for each batch element.

outOptional[wp.array]= None

Optional caller-owned output with shape (batch, frames, 7 + dofs).

target_overridesOptional[Dict[str, np.ndarray]]= None

Optional (batch, frames, 7) target tracks keyed by robot link; they move the IK warm start and TARGET_POSITIONS, while orientation templates read TARGETS (the mapped poses) unless they read OVERRIDDEN_TARGETS.

Returns
wp.array

out when provided; otherwise a reusable helper-owned buffer overwritten by the next call.
