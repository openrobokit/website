User Guide

Overview

RoboKit is a high-performance, general-purpose toolkit for versatile robotic tasks. It scales from one problem to thousands in parallel. It provides a library of cost terms and optimizers that compose freely. Built-in tasks such as IK, motion planning, and retargeting are validated on real robots.

Thousands of robots solving in parallel.

Benchmarks

Bars are wall-clock time on the same task, baseline normalized to full width. Check the paper for benchmark details.

How it works

ComponentRoleRead more
RobotLoad URDF or MJCF models and compute batched, differentiable kinematics.Robot
ObjectivesCost terms that define a task: pose matching, collision, limits, contacts.Terms
OptimizersSampling and gradient methods that minimize the objectives in parallel.Optimization
AccelerationFast geometry and rendering for contact-rich and calibration tasks.Geometry
DistillationTrain policies on solver outputs for even faster inference.

Installation

Requires Python 3.8 or newer:

shell
uv add robokit      # or: pip install robokit

PyTorch is optional. See Installation for source installs and extras.
