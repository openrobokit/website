Installation

RoboKit needs Python 3.8 or newer.

shell
uv add robokit
shell
pip install robokit

From source

shell
uv add git+https://github.com/openrobokit/robokit
shell
pip install git+https://github.com/openrobokit/robokit

To work on RoboKit itself, follow the Development Guide.

Extras

ExtraWhat it adds
mjMJCF loading (assembly needs mujoco 3.3.4+, Python 3.9+).
mjwarpMuJoCo Warp for SimMPC (Python 3.10+).
pt-cu126, pt-cu118, pt-cu128, pt-cpuPyTorch for your CUDA toolkit.

The mask-alignment term and camera calibration also need nvdiffrast built for your exact PyTorch and CUDA, such as pip install "nvdiffrast==0.3.3+pt2.11.0cu126" --extra-index-url https://jianglongye.github.io/torch_packages_builder.
